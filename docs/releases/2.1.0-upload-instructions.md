# 2.1.0 업로드 안내 — 작성자용

실제 공개 릴리즈와 태그는 아직 만들지 않았습니다.

1. GitHub 저장소의 Releases에서 새 릴리즈 작성을 엽니다.
2. 태그는 `v2.1.0`, 대상은 준비 완료한 소스 커밋을 선택합니다. 전달 폴더의 `BUILD-INFO.json`에 정확한 커밋이 기록됩니다.
3. 제목은 `2.1.0 Releases`로 입력합니다.
4. `release-notes.md` 내용을 본문에 그대로 붙여넣습니다.
5. **`SPT-KR-2.1.0.zip` 하나를 첨부**합니다. 원하는 경우 `SHA256SUMS.txt`도 첨부할 수 있습니다.
6. 미리보기에서 설치 방법과 지원 범위를 확인한 뒤 직접 게시합니다.

`verification.json`, `BUILD-INFO.json`, `upload-instructions.md`는 작성자 확인용입니다. ZIP에 다시 넣거나 모두 첨부할 필요가 없습니다.
기존 2.0.1 릴리즈와 파일은 그대로 두고 새 릴리즈로 게시하세요.

ZIP은 서버 모듈 없이 `BepInEx/plugins` 아래의 파일만 포함합니다. 이전 한글화 서버 모드를 제거하라는 업데이트 안내를 본문에서 빼지 마세요.
