# SPT 한글화 2.1.0 설치 안내

`SPT-KR-2.1.0.zip` 하나에 기본 한글판과 전체 한영 병기판이 들어 있습니다.
설치된 SPT 버전에 맞는 번역을 플러그인이 선택합니다. 서버 모드는 필요하지 않습니다.

## 설치 및 기존 버전에서 업데이트

1. 게임과 SPT 서버를 종료합니다.
2. 이전 한글화 모드가 있다면 아래 해당 폴더를 **모드 검색 경로 밖으로 백업한 후 제거**합니다. `user/mods` 전체나 세이브 폴더는 삭제하지 마세요.

| 사용하던 모드 | 제거할 폴더 |
| --- | --- |
| 3.x 기존 서버 한글화 | `user/mods/spt_korean_localization_G&M` |
| 4.0 기존 서버 한글화 | `SPT/user/mods/SPT_Korean_Localization` |
| 4.1 기존 서버 한글화 | `SPT_Runtime/user/mods/SPT_Korean_Localization` |
| 테스트용 서버 안내 | 해당 서버의 `user/mods/GoLani.KoreanLocalization.Status` |
| 오래된 alpha 서버 모드 | 해당 서버의 `user/mods/spt_korean_localization_alpha_test_gm` |

3. `BepInEx/plugins/GoLani.KoreanModFix.dll`이 다른 하위 폴더에도 있다면 이전 복사본을 백업 후 제거합니다. 같은 플러그인이 두 번 설치되지 않도록 합니다. 테스트판의 `SPT-Korean` 폴더도 백업 후 제거하고 새 파일을 넣으세요. 백업 DLL은 `BepInEx/plugins` 아래에 두면 안 됩니다.
4. ZIP 안의 **BepInEx 폴더를 `EscapeFromTarkov.exe`가 있는 게임 최상위 폴더로** 끌어다 놓습니다. 같은 파일을 덮어쓸지 물으면 덮어쓰기를 선택합니다.
5. 평소처럼 서버와 게임을 실행합니다.
6. `설정 > 게임 > 인터페이스 언어`에서 `한국어 (Korean)` 또는 `한국어 (한영 병기)`를 선택합니다. 재설치 없이 두 모드를 전환할 수 있습니다.

설치 결과:

```text
게임 최상위 폴더/
├─ EscapeFromTarkov.exe
└─ BepInEx/
   └─ plugins/
      ├─ GoLani.KoreanModFix.dll
      └─ SPT-Korean/
         ├─ manifest.json
         ├─ locales/버전별 번역 데이터
         ├─ README-ko.md
         └─ LICENSE-*.txt
```

ZIP에는 설치 프로그램, 서버 모듈, 게임 실행 파일, 개인 설정이나 세이브가 없습니다.
기존 테스트판에서 모드 버전 2.2.0을 보셨더라도 이번 정식 배포의 표시는 2.1.0입니다. 테스트한 기능을 되돌린 것이 아닙니다.

## 적용 범위

- 명시된 번역 프로필: SPT 3.8.3, 3.9.8, 3.10.5, 3.11.4, 4.0.13, 4.1.0, 4.1.2, 4.1.3, 4.1.5.
- 등록되지 않은 안정판 4.1.x 중 4.1.2 이상~4.2.0 미만은, EFT 게임 빌드·영어 원문·필요한 게임 함수가 호환될 때 기존 프로필을 사용합니다.
- SPT 4.1.1, 시험판, 4.2 이상 및 다른 미등록 버전은 자동 허용하지 않습니다.
- 같은 설치 폴더 안에 해당 버전의 SPT 서버 데이터가 있어야 합니다. 원격 서버만 사용하는 게임 전용 설치본은 지원하지 않습니다.
- 원문이나 게임 빌드가 바뀌면 이전 번역으로 덮지 않고 적용을 중단합니다.

3.8.3·3.9.8·3.10.5·3.11.4·4.1.5는 설치된 게임 파일과 실행 환경으로 자동 검증했습니다.
4.0.13·4.1.0·4.1.2·4.1.3은 번역 데이터와 모의 실행 흐름을 검증했으며, 이번 배포 준비 과정에서 해당 게임 화면을 직접 확인한 것은 아닙니다.

## 적용 확인

서버를 켰을 때 한글화 안내가 표시되지 않는 것이 정상입니다.
게임 실행 후 `BepInEx/LogOutput.log`에서 아래 문구와 SPT 버전·번역 기준·항목 수를 확인하세요.

```text
[고라니 SPT 한글화 v2.1.0 | SPT ...] 번역 데이터 로드 및 언어 패치 적용 완료!
```

이 문구는 번역 데이터와 언어 패치의 초기화 결과입니다. 개별 UI 보정 결과는 같은 로그의 `Enabled`, `Unavailable`, `failed` 항목에 표시됩니다. 예전 버전에 없는 기능이 `Unavailable`로 표시되는 것은 정상일 수 있습니다.

게임/다른 모드가 이미 완성된 문장으로 전달하는 일부 메시지는 번역 대상에서 벗어날 수 있습니다.
오역이나 오류는 SPT 버전, 언어 모드, 발생 위치와 관련 로그를 함께 알려 주세요.

## 설정 및 복구

이 패치는 그래픽 설정이나 NVIDIA 설정을 바꾸지 않습니다. 서로 다른 SPT 버전 사이에 그래픽 설정을 그대로 복사하면 로딩에 실패할 수 있습니다.
테스트 중 확인된 NVIDIA `NvPresent64.dll` 충돌은 스무스 모션을 끈 비교 실행에서 발생하지 않았습니다. 같은 충돌이 있는 경우 해당 옵션을 꺼 비교해 볼 수 있으며, 모든 종료 오류가 같은 원인이라는 뜻은 아닙니다.

되돌리려면 먼저 게임 언어를 기본 한국어로 변경하고 게임·서버를 종료한 뒤, 이번 DLL과 `SPT-Korean` 폴더를 제거하고 백업한 기존 한글화 파일을 복원하세요.
