### SPT 한글화 프로젝트 2.1.0

이제 **`SPT-KR-2.1.0.zip` 하나**로 지원하는 여러 SPT 버전에 설치할 수 있습니다.
기본 한글판과 전체 한영 병기판이 함께 들어 있으며, 게임 설정에서 표시 방식을 선택합니다.

## 주요 변경 사항

- 한글화와 UI 보정을 `BepInEx/plugins`에 통합했습니다.
- 버전별·언어별 ZIP 대신 공통 ZIP 하나를 제공합니다.
- 게임 재시작이나 파일 재설치 없이 한국어와 한영 병기를 전환할 수 있습니다.
- 새로운 4.1.x 패치는 게임 빌드와 원문 등이 호환되는 경우 기존 번역을 사용합니다.
- 아이템 짧은 이름 보정을 실제 이름 갱신 시점에 적용하고, 영어로 전환하면 원래 표시 설정을 복원합니다.
- 모드 버전과 번역 적용 결과는 게임의 `BepInEx/LogOutput.log`에 기록합니다. 별도 서버 안내 모듈은 제공하지 않습니다.

## 다운로드

**첨부된 `SPT-KR-2.1.0.zip` 하나만 받아 주세요.**
기본 한글판과 한영 병기판을 따로 받을 필요가 없습니다. GitHub가 자동으로 표시하는 `Source code`는 설치용 파일이 아닙니다.

## 설치 / 업데이트

1. 게임과 서버를 종료합니다.
2. 기존 서버 한글화 모드와 테스트용 안내 모듈이 있다면 아래 해당 폴더를 모드 검색 경로 밖에 백업한 후 제거합니다. `user/mods` 전체나 세이브는 삭제하지 마세요.

| 기존 설치 | 제거할 폴더 |
| --- | --- |
| SPT 3.x 서버 한글화 | `user/mods/spt_korean_localization_G&M` |
| SPT 4.0 서버 한글화 | `SPT/user/mods/SPT_Korean_Localization` |
| SPT 4.1 서버 한글화 | `SPT_Runtime/user/mods/SPT_Korean_Localization` |
| 테스트용 안내 모듈 | 해당 서버의 `user/mods/GoLani.KoreanLocalization.Status` |

3. 기존 `GoLani.KoreanModFix.dll`과 테스트판의 `SPT-Korean` 폴더도 백업합니다. 중복 DLL과 이전 번역 폴더는 제거하며, 백업은 `BepInEx/plugins` 밖에 둡니다.
4. ZIP 안의 **BepInEx 폴더를 `EscapeFromTarkov.exe`가 있는 게임 폴더로** 끌어다 놓습니다.
5. 서버와 게임을 실행한 뒤 `설정 > 게임 > 인터페이스 언어`에서 원하는 표시 방식을 선택합니다.

```text
BepInEx/plugins/
├─ GoLani.KoreanModFix.dll
└─ SPT-Korean/
   ├─ manifest.json
   ├─ locales/
   └─ README-ko.md
```

서버 콘솔에 한글화 안내가 나오지 않아도 정상입니다. 게임 실행 후 `BepInEx/LogOutput.log`에서 `[고라니 SPT 한글화 v2.1.0`으로 시작하는 적용 결과를 확인할 수 있습니다.

## 지원 및 확인 범위

- 번역 프로필: **3.8.3 / 3.9.8 / 3.10.5 / 3.11.4 / 4.0.13 / 4.1.0 / 4.1.2 / 4.1.3 / 4.1.5**.
- 미등록 안정판 4.1.x는 **4.1.2 이상, 4.2.0 미만**에서 호환성 검사를 통과할 때만 기존 번역을 사용합니다. 4.1.1과 시험판은 제외합니다.
- **게임과 같은 설치 폴더에 해당 버전의 SPT 서버 데이터가 필요합니다.** 원격 서버만 사용하는 게임 전용 설치본은 지원하지 않습니다.
- 3.8.3·3.9.8·3.10.5·3.11.4·4.1.5의 설치된 게임 파일과 실행 환경으로 자동 검증했습니다. 나머지 명시 버전은 번역 데이터와 모의 동작을 검증했으며, 실제 화면 확인과는 구분됩니다.
- 호환성 검사에 실패하면 로그에 원인을 기록하고 적용하지 않습니다. 모든 후속 버전이나 다른 모드와의 조합을 무조건 지원한다는 뜻은 아닙니다.

기본 한글판에도 기존 번역 방식에 따라 일부 영문 이름이 함께 표시될 수 있습니다. 서버나 다른 모드가 직접 만든 일부 문장은 번역되지 않을 수 있습니다.

## 참고

테스트판에 표시되던 2.2.0은 시험용 번호였습니다. 이번 정식 배포는 **2.1.0**이며 최근 테스트한 기능을 포함합니다.

이 패치는 개인 세이브·게임 그래픽 설정·NVIDIA 설정을 변경하지 않습니다. 다른 버전의 그래픽 설정 복사로 인한 로딩 오류나 드라이버 충돌은 별도로 확인해야 합니다.

오역·미번역·오류는 [Issues](https://github.com/GoLani11/SPT-Korean-Project/issues)에 SPT 버전, 언어 모드, 발생 위치와 관련 로그를 첨부해 알려 주세요.
